# 택배요청서 변환 대시보드

인보이스 PDF를 **출고요청서 엑셀**로 자동 변환하는 Streamlit 대시보드입니다.

---

## 폴더 구조

```
택배요청서 변환 대시보드/
├── app.py                  ← 메인 대시보드 앱
├── config.json             ← API 키 등 설정 저장 파일
├── requirements.txt        ← 필요 패키지 목록
├── 실행.bat                ← 더블클릭으로 앱 실행
├── README.md
├── utils/
│   ├── pdf_parser.py       ← PDF 파싱 로직 (ABSORBLAB/CELIMAX 인보이스 기준)
│   ├── excel_exporter.py   ← 엑셀 출력 로직
│   ├── postal_code.py      ← 카카오 로컬 API 우편번호 자동 조회
│   ├── db_manager.py       ← 품목코드 DB 관리
│   └── config_manager.py   ← 설정 파일 입출력
└── data/
    └── 품목코드DB.csv       ← 품목 매핑 데이터베이스
```

---

## 실행 방법

`실행.bat`을 더블클릭하면 브라우저가 자동으로 열립니다 (`http://localhost:8501`).

---

## 주요 기능

### 📄 Tab 1 — 인보이스 변환

1. 인보이스 PDF 업로드 (ABSORBLAB / CELIMAX 양식)
2. 자동 추출 항목:
   - **수령자** / **연락처** / **주소** (Forwarder Information 섹션)
   - **바코드** / **영문품목명** / **수량** / **단가** (Products 테이블)
3. 바코드 기준으로 품목코드 DB를 조회해 **어드민코드 · 한글품목명** 자동 매핑
4. 카카오 로컬 API로 **우편번호** 자동 조회
5. 내용 수정 후 **출고요청서 엑셀(.xlsx) 다운로드**

#### 엑셀 출력 컬럼 구조
| A: 품목명(어드민코드) | B: 수량 | C: 매입가(VAT포함) | D: 수령자 | E: 연락처 | F: 주소 | G: 우편번호 | H: 배송메모 |

#### 파싱 진단 박스
- **1단계** — PDF에서 바코드/품목명 추출 성공 여부 확인
- **2단계** — DB 매칭 실패 시 '품목코드 DB 관리' 탭에서 해당 바코드 등록 안내

### 🗂 Tab 2 — 품목코드 DB 관리

바코드를 기준으로 **영문품목명 → 어드민코드 · 한글품목명** 매핑을 관리합니다.

| 컬럼 | 설명 |
|------|------|
| 바코드 | EAN-13 등 스캔 바코드 |
| 영문품목명 | PDF에 표기된 영문명 |
| 한글품목명 | 한글 상품명 |
| 어드민코드 | 출고요청서 품목명 열에 기재될 코드 |
| 비고 | 메모 |

- **엑셀/CSV 가져오기** — 기존 파일 일괄 업로드
- **엑셀 내보내기** — 현재 DB 다운로드
- **💾 저장** — 변경사항 저장

### 🔍 Tab 3 — PDF 진단

파싱이 안 될 때 pdfplumber가 PDF에서 실제로 추출하는 원시 텍스트와 테이블 구조를 확인합니다.

---

## PDF 파싱 구조 (ABSORBLAB / CELIMAX 인보이스 기준)

pdfplumber가 Products 테이블 전체를 **하나의 병합 셀**로 추출하는 특성에 맞게 구현되어 있습니다.

```
Unit
No. Product Name  Barcode         HSCode        Quantity  Subtotal  Memo
Price(KRW)
CELIMAX THE REAL NONI
1  MOISTURE BALANCING  8809954940132  3304.99.1000  9,625.00  24  231,000.00  -
TONER 150ML
```

파싱 전략:
1. 바코드 패턴(`\d{8,14}`)과 행번호(`^\d+\s`)가 모두 있는 줄 = 데이터 행
2. 데이터 행 **이전** 순수 텍스트 줄 + 데이터 행 바코드 앞부분 + 데이터 행 **이후** 순수 텍스트 줄 → 품목명 조합
3. 바코드 이후: HSCode 제거 → 첫 번째 숫자 = 단가, 두 번째 숫자 = 수량

## 우편번호 자동 조회 설정

카카오 로컬 API(주소 검색)를 사용합니다. 무료이며 하루 300,000건 한도.

### 최초 설정
1. [developers.kakao.com](https://developers.kakao.com) 접속 → 애플리케이션 추가
2. 왼쪽 메뉴 **카카오맵** → 활성화
3. **플랫폼 키** 에서 **REST API 키** 복사
4. `config.json` 파일에 아래와 같이 저장:
   ```json
   {
     "kakao_api_key": "여기에_REST_API_키_입력"
   }
   ```

> **403 오류 발생 시**: 카카오 콘솔 → 해당 앱 → 카카오맵 활성화 여부 확인

## 품목코드 DB 관리 방법

### 엑셀로 일괄 등록
컬럼명이 정확히 일치하는 엑셀/CSV 파일을 준비하세요:
```
바코드 | 영문품목명 | 한글품목명 | 어드민코드 | 비고
```
'🗂 품목코드 DB 관리' 탭 → **엑셀 가져오기**로 업로드

### 개별 등록
'🗂 품목코드 DB 관리' 탭 → 테이블 하단 빈 행에 직접 입력 → **💾 저장**
